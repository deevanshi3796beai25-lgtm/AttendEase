AttendEase – Smarter Attendance, Simpler Classrooms

AttendEase is a frontend concept website for a smart classroom attendance management system, built using pure HTML and CSS — no JavaScript, no backend. The platform imagines a clean, modern way for teachers to track attendance, engage students, and view insights, all wrapped in a calming blue-and-white interface.

It is designed to showcase what a smart, secure, and student-friendly attendance product could look like, from the login screen to daily attendance marking to analytics.

🚀 Features
🏠 Landing page with animated loader and hero dashboard preview
✅ Attendance marking interface
📊 Attendance analytics dashboard
🎡 Interactive spin wheel for random student selection
🔐 Anti-proxy verification demo (QR-based concept)
🔑 User authentication pages (Login / Sign Up)
✉️ Contact page with form
📱 Fully responsive design
🎨 Glassmorphism UI with clean, modern styling
🛠️ Technologies Used
HTML5
CSS3 (including CSS-only interactivity — checkbox hack, animations, transitions)
Responsive Web Design

💡 Purpose of the Project

AttendEase was created to demonstrate:

Clean, responsive frontend design
Interactive UI built entirely without JavaScript
A realistic multi-page product website structure
Practical use of CSS-only tricks for menus, loaders, and animations

The project focuses on frontend craftsmanship — building a polished, cohesive experience using only markup and styling.
